# @glyphweave/typst

Part of the [Glyphweave](https://github.com/EricYuan2007/Glyphweave) build-time Typst publishing pipeline.

See the repository [documentation](https://github.com/EricYuan2007/Glyphweave/tree/main/docs) for configuration and artifact contracts. Build with `pnpm build` from a checkout. Distributed packages expose JavaScript and TypeScript declarations and require Node.js 22.18+. Typst compilation additionally requires Typst 0.15.0.
