# Support

Start with the [documentation index](docs/README.md), [troubleshooting guide](docs/troubleshooting.md),
and `glyphweave doctor`. Search existing issues before opening a report.

Use the bug template for reproducible failures and the feature template for new
workflows. Include your OS, Node/pnpm/Typst versions, revision, and redacted logs.
Security concerns follow [SECURITY.md](SECURITY.md). This is a community-maintained
project without a commercial support or response-time guarantee.
